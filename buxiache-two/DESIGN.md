# 《不下车 · 各执一词》设计稿

> 你能改的只有你自己。她的反应永远是既成事实。

## 一、一句话

你扮演许飞或厉娜，回到六个年份里任意一年，重新决定当时的自己怎么做。
但**另一方的行为锁死在档案里**——你重来一百次，她还是她。
最后一夜，你把你的版本和她的版本并排放在一起，游戏拒绝裁决。

## 二、为什么是这个机制

原始想法是"穿越改剧情"。直接做会变成普通的时间旅行视觉小说，而且会替真人认下没有证据的事。

改一个字就好：**能改的只有自己。**

- 玩法上：你获得全部主动权，同时立刻撞上"改变不了别人"这堵墙。这是这个题材真正的痛点。
- 伦理上：我们不编造任何一方的行为，只让玩家承担自己的选择。另一方的每个反应都能在公开报道里找到出处。

## 三、两层世界

| 层 | 是什么 | 谁决定 |
|---|---|---|
| **档案** | 公开发生过的事：日期、赛果、报道、同台记录 | 已发生，不可改 |
| **记忆** | 你的版本：你当时做了什么、说了什么 | 你决定 |

每改一次，两层裂开一道缝。游戏不告诉你谁对，只把缝并排给你看。

**档案卡有三种戳：**

- `✅ 公开可查` —— 有播出画面或多家报道。改它，裂痕重（+2）。
- `⚠️ 只有一方说法` —— 一方指认、一方否认。改它，裂痕轻（+1）。
- `❓ 无法证实` —— 流传的截图、解读、动机。改它，不记裂痕，记「说不清」。

这个分级不是装饰，是玩法。**玩家第一次意识到"有些事本来就没有答案"的那一刻，就是这个游戏的高潮。**

## 四、主界面：时间轴

六个年份横排。解锁一个亮一个。可以跳回任何一年重来。

资源是**六格电**，跳一次耗一格。最多改五次，必须取舍。

```
┌──────────────────────────────────────────────────────┐
│  ▮▮▮▮▮▮                                              │
│                                                      │
│   2006.6   2006夏   2007.11   2020.4   2026.10   ▣   │
│     ●        ●        ●         ●        ●     终局  │
└──────────────────────────────────────────────────────┘
```

## 五、单场景循环

> 进场景 → 一句内心独白 → 三个选项（+ 一个灰的） → 后果一句话 → 回时间轴

### 选项的四种结果

| 类型 | 效果 |
|---|---|
| **符合档案** | 裂痕 0 |
| **偏离档案** | 裂痕 +1 / +2（看档案戳的可信度） |
| **沉默** | 裂痕 0，但记「没说出口」 |
| **灰色的** | 你可以点。点了之后她说：**「这句话你没说出口。」** 一样耗电，一样回时间轴。 |

**灰选项是这个游戏最重要的一格。** 它让"没说出口"变成一种可以被玩家主动选择的失败。

## 六、两个人的动词不一样

同样六个节点，**许飞的动词比厉娜多**。

- 许飞：`说` `问` `当面讲` `打电话` `写下来` `沉默`
- 厉娜：`等` `忍` `笑一下` `转身` `沉默`

不是数值平衡，是处境不同。玩家切换角色时会立刻感觉到：**在她的位置上，能说的话本来就少一些。**

实现上：同样的场景，两套选项表。不做成"解锁"，就摆在那儿，让你看见自己少的那几个。

## 七、竖切范围（先做这个）

**3 个节点 × 2 个角色 + 终局 + 2 个结局**，约 15 分钟一轮，两轮看全。

| 节点 | 场景 | 档案戳 |
|---|---|---|
| 2006 夏 · PK 台 | 直播，灯很亮 | ✅ |
| 2007.11 · 那三句话 | 凌晨，论坛，两千一百多楼 | ⚠️ 罗生门 |
| 2026.10 · 高原 | 海拔 4000 米，风很大 | ✅ + ⚠️ |
| 终局 2026.11 · 下车 | 节目组让每人说一句话 | — |

## 八、场景脚本

### 节点一 · 2006 年夏 · 直播

**档案卡**

```
2006 年夏 · 长沙赛区 PK 环节
主持人问厉娜投票标准。
她说：「于公于私，于情于理。」
然后举起了许飞的手。
✅ 公开可查 · 有播出画面
```

**扮演厉娜**

> 话筒递到我手里的时候，我脑子里只有一个念头：别让她走。

- 说「于公于私，于情于理」，举起她的手 → **符合档案**
- 说「她唱得比我好」，不举手 → **裂痕 +2**
- 什么都不说，直接举手 → **沉默**（裂痕 0，记「没说的话」）
- 〔灰〕「我其实……」→ **没说出口**

**扮演许飞**

> 她举手的时候，我没敢看她。

- 握紧她的手 → **符合档案**
- 把手抽回来 → **裂痕 +2**
- 低着头，等她放下 → **沉默**
- 〔灰〕「你为什么选我」→ **没说出口**

---

### 节点二 · 2007 年 11 月 · 那三句话

**档案卡**

```
2007 年 11 月 · 天涯娱乐八卦
一个帖子，三句话。跟了两千一百多楼。
原帖已删。流传的截图来源不明。
许飞指认；厉娜先否认，后被追问时改口
「也许话赶话提过，但没点名」。
—— 没有第三方证据。没有任何一方被证实。
⚠️ 罗生门 · 无第三方证据
```

> **这是全游戏唯一一张空档案。**
> 整份资料里最重的一件事，什么都没有。无论玩家选什么，这一格永远是空的。

**扮演许飞**

> 我第一个想到的不是帖子，是她。

- 不问。自己扛 → **符合档案**（此后近七年，行程近乎全空）
- 打电话问她 → **裂痕 +1**（档案里没有这通电话的记录）
- 发一条短信：「你看到那个帖子了吗」 → **裂痕 +1**
- 〔灰〕「是不是你」→ **没说出口**（无论点不点，这一格永远不解）

**扮演厉娜**

> 手机响的时候，我在想，接了要说什么。

- 接，说「不是我」 → **符合档案**（她先否认）
- 不接 → **裂痕 +1**
- 接，说「也许话赶话提过」 → **符合档案**（她后来确实这么说），但打上「**改口**」标记
- 〔灰〕「你信我吗」→ **没说出口**

---

### 节点三 · 2026 年 10 月 · 海拔四千米

**档案卡**

```
2026 年 10 月 · 悬崖小屋 · 海拔约 4000 米
她说：「我画地为牢。」
回屋后，她用 AI 查了「画地为牢」的意思，
然后点了麦当劳。
✅ 公开可查 · 有节目画面
⚠️ 「她在等谁」是网友逐帧读出来的，无当事人确认
```

**扮演厉娜**

> 我不知道那个词是什么意思。我就是觉得，站在这儿，走不出去。

- 说出「我画地为牢」 → **符合档案**
- 笑一下，说「风好大」 → **裂痕 +1**
- 什么都不说 → **沉默**
- 〔灰〕「你听懂了吗」→ **没说出口**

**扮演许飞**

> 她说那四个字的时候，我在想怎么接。

- 沉默 → **符合档案**
- 说「那我陪你关在里面」 → **裂痕 +1**（档案里没有这句）
- 说「下山吃饭」 → **裂痕 +1**
- 〔灰〕「你是不是在等我」→ **没说出口**

---

### 终局 · 2026 年 11 月 · 下车

节目组让每人说一句「这些年最想对对方说的话」。你想留下，还是下车？

**结算画面**：左边你的版本，右边她的版本（由档案生成，固定不变）。两道缝并排。

**结局**

| 结局 | 条件 |
|---|---|
| 《各自安好》 | 裂痕 0 |
| 《说不清》 | 裂痕 ≥ 3 |
| 《下车》 | 终局选下车 |
| 《不下车》 | 终局选留下，并说完了那句话 |
| 《各执一词》 | 真结局：两线都通关后解锁，游戏拒绝裁决 |

**《各执一词》的最后一句**（全游戏唯一一句"作者的话"）：

> 你们说的都是真的。
> 只是不是同一件事。

## 九、技术方案

- **单 HTML，无构建**，双击即玩，和 v3 一个路子。
- **画面**：Canvas 程序化生成，扫描件质感的档案卡、掉帧影像、失真波形。零外部素材，离线可玩。
- **文字**：DOM 排版，宋体，字距放宽。
- **声音**：WebAudio 现场合成——雨、列车、掌声、走廊回声。不加载任何音频文件。
- **存档**：localStorage，两个角色各一档，各自记裂痕数、沉默数、通关标记。
- **剧本**：JSON 内联，节点/选项/后果/档案戳全部数据驱动，改词不用碰逻辑。

目录：`games/buxiache-two/`

## 十、创作边界

- 玩家扮演的是**记忆里的人**，不是现实里的人。开场第一屏就写清楚：这是一次重构，不是还原。
- 「告密」永远不给答案。四个选项都不解锁真相——现实里也没有第五个选项。
- 不用真人照片、不用节目影像、不用节目 LOGO、不写私生活。
- 所有判断留给玩家。游戏不下结论，只把两个版本并排放着。
