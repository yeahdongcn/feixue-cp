# 不下车 · 各执一词

扮演许飞或厉娜，回到任何一个年份，重新决定当时的自己怎么做。
但另一方不归你管——她的反应锁在**档案**里。你能改的只有你自己。

单文件，双击 `index.html` 即玩。零外部资源，画面与噪点全部代码实时生成。

---

## 怎么玩

1. 开场选一个人：**许飞** 或 **厉娜**。
2. 时间轴上三站，每回去一次，用掉一格电（一共 6 格）。
3. 每站先看**档案卡**——那是这一年的公开记录，右上角标着可信度。
4. 然后做选择。三个正常选项，外加一个**灰选项**（虚线框）：点了之后她说「这句话你没说出口」，一样耗电，一样回时间轴。
5. 三站走完，终局解锁。结局把你的版本和她的版本并排放，**不裁决**。

## 核心设计

**你只能改你自己。** 另一方的行为是写死的档案，不管你重来多少次，她还是她。这是整个游戏的主张：回到过去也改变不了别人。

**灰选项不做成解锁。** 两套动词表就摆在那儿——许飞的动词多（说、问、打电话），厉娜的少（等、忍、笑一下、转身）。不做成"玩够多少解锁"，就让你看见自己少的那几个。有选项的那一刻，你已经在失去它。

**那一格永远是空的。** 2007 年那个节点，厉娜指控、许飞否认，没有录音也没有第三方证据。无论玩家选什么，这一格都是空的，并且写着「没有第三方证据」。

**结局不判案。** 左右两栏，一栏是你说的话，一栏是她说的话。最后一行是：

> 你们说的都是真的。只是不是同一件事。

## 三站

| 年份 | 事件 | 档案可信度 |
|---|---|---|
| 2006 · 夏 | PK 台，她举起了她的手 | ✅ 公开可查，有播出画面 |
| 2007 · 冬 | 一次被传出去的谈话，厉娜指控许飞告密 | ⚠️ 罗生门，无第三方证据 |
| 2026 · 10 | 海拔四千米，许飞说「我画地为牢，厉娜」 | ✅ 有节目画面；「她在等谁」无当事人确认 |

## 技术

- 单文件 `index.html`，无构建、无依赖、无网络请求。
- 剧本是内联 JSON 数据驱动：加年份、加选项、改后果都不用碰逻辑。
- 背景：色团 + 扫描线 + 划痕 + 暗角；年份水印只画在内容列之外（桌面在右侧留白，手机在底部安全区），不再压住卡片和按钮。
- 档案卡上的影像残片是按节点画的一帧：PK 台（两束追光 + 两个人影，右边那个举着手）、走廊尽头（一个背影 + 门缝的光 + 失焦撕裂）、高原（山脊 + 月亮 + 亮着一扇窗的小屋 + 雪），带胶片角标、REC 时间码和颗粒。
- 画面全部用 Canvas 2D 现画，没有一张图片文件。
- 噪点是 128×128 `ImageData` 随机像素做成的 dataURL。
- 存档走 `localStorage`，键 `gezhiyici.v1`。
- 测试：`node test/run.js`（真 Chromium 驱动，40 条断言，含零报错检查）。


## 声音

全部 WebAudio 现场合成，**没有任何音频文件，也没有任何真实歌曲的旋律**。

- **66 BPM**，A 小调。四音动机 `A4 C5 E5 D5 C5 B4 A4 G4`（八分音符，一拍一个）是这个系列四个游戏的共同签名；这里只取片段、换八度，用留白把它拉宽。
- 三层：**钢琴**（正弦 + 三角波，4ms 起音 / 0.9s 衰减）走动机；**弦垫**（两个失谐锯齿 + 900Hz 低通，0.6s 起音）铺和声，两小节换一次；**低音**与**钟**（正弦 + 高八度泛音，0.25s 包络）只在段落转折处点一下。
- 每站一套配置：PK 台稍亮（加低音鼓），2007 更暗（低通 680Hz、有撕裂感），高原最空（只留动机的两三个音），结局回到完整动机。
- 前瞻调度：`setInterval` 25ms，提前 0.12s 排音符；主输出 `GainNode` 0.18，进游戏后 1.2 秒线性淡入；换站/换时代 1.5 秒交叉淡入。
- 首次加载不出声（浏览器自动播放策略），第一次点击/按键后才 `resume`。**M** 或右上角小喇叭静音，状态存 `localStorage`。
- 键盘：`1`–`4` 选项，`Esc` 退出场景（退还这次的电）/ 退出档案，`Enter` 进场，`M` 静音。

## 边界

这不是还原，是一次重构。人物是真实的公众人物，情节基于公开报道改编，**不构成对任何人的事实主张**。

- 不使用任何真人照片、节目 LOGO 或节目影像，所有画面由代码生成。
- 不对"告密"一节下任何结论——没有第三方证据，游戏内保持罗生门。
- 玩家扮演的是记忆里的人，不是现实里的人。

## 已知问题

- 只有三站 + 一个终局，是竖切不是完整版。原设计六站。
- 电量系统在竖切里永远用不完（6 格电 / 3 站），失败状态见不到。
- 她的版本目前是固定文案，还没有跟玩家的历史选择产生交叉影响。
- 声音是排好的动机循环，还不会跟着剧情紧张度变化；也没有音效（脚步、雨、关门），只有音乐。
- 结局页的复制一句话依赖 `navigator.clipboard`；`file://` 下退回 `execCommand`，再不行就静默失败。
