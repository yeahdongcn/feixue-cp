# 不下车 · 各执一词

扮演许飞或厉娜，回到任何一个年份，重新决定当时的自己怎么做。
但另一方不归你管——她的反应锁在**档案**里。你能改的只有你自己。

单文件，双击 `index.html` 即玩。零外部资源，画面与噪点全部代码实时生成。

---

## 怎么玩

1. 开场选一个人：**许飞** 或 **厉娜**。
2. 时间轴上三站，每回去一次，用掉一格电（一共 6 格）。
3. 每站先看**档案卡**——那是这一年的公开记录，右上角标着可信度。
4. 然后做选择。三个正常选项，外加一个**灰选项**（虚线框）：点了之后她说「这句话你没说出口」，一样耗电，一样回时间轴。
5. 三站走完，终局解锁。结局把你的版本和她的版本并排放，**不裁决**。

## 核心设计

**你只能改你自己。** 另一方的行为是写死的档案，不管你重来多少次，她还是她。这是整个游戏的主张：回到过去也改变不了别人。

**灰选项不做成解锁。** 两套动词表就摆在那儿——许飞的动词多（说、问、打电话），厉娜的少（等、忍、笑一下、转身）。不做成"玩够多少解锁"，就让你看见自己少的那几个。有选项的那一刻，你已经在失去它。

**那一格永远是空的。** 2007 年那个节点，档案里没有第三方证据，只有双方各执一词。无论玩家选什么，这一格都是空的，并且写着「没有第三方证据」。

**结局不判案。** 左右两栏，一栏是你说的话，一栏是她说的话。最后一行是：

> 你们说的都是真的。只是不是同一件事。

## 三站

| 年份 | 事件 | 档案可信度 |
|---|---|---|
| 2006 · 夏 | PK 台，她举起了她的手 | ✅ 公开可查，有播出画面 |
| 2007 · 11 | 天涯那三句话 | ⚠️ 罗生门，无第三方证据 |
| 2026 · 10 | 海拔四千米，「我画地为牢」 | ✅ 有节目画面；「她在等谁」无当事人确认 |

## 技术

- 单文件 `index.html`，无构建、无依赖、无网络请求。
- 剧本是内联 JSON 数据驱动：加年份、加选项、改后果都不用碰逻辑。
- 背景的"记忆残片"是每次进入节点现场生成的：色团 + 扫描线 + 划痕 + 年份水印 + 暗角，同一个节点种子固定。
- 档案卡上的"影像残片"同理，另外按可信度分两种画法（`solid` / `ruin`，后者带撕裂黑条）。
- 噪点是 128×128 `ImageData` 随机像素做成的 dataURL。
- 存档走 `localStorage`，键 `gezhiyici.v1`。
- 测试：`node test/run.js`（真 Chromium 驱动，35 条断言）。

## 边界

这不是还原，是一次重构。人物是真实的公众人物，情节基于公开报道改编，**不构成对任何人的事实主张**。

- 不使用任何真人照片、节目 LOGO 或节目影像，所有画面由代码生成。
- 不对"告密"一节下任何结论——没有第三方证据，游戏内保持罗生门。
- 玩家扮演的是记忆里的人，不是现实里的人。

## 已知问题

- 只有三站 + 一个终局，是竖切不是完整版。原设计六站。
- 电量系统在竖切里永远用不完（6 格电 / 3 站），失败状态见不到。
- 她的版本目前是固定文案，还没有跟玩家的历史选择产生交叉影响。
- 没有音效。设计里写了用 WebAudio 现场合成雨声和走廊回声，这一版还没做。
