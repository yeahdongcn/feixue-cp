# 不下车 · 一盒磁带，六个夏天

2D 像素 JRPG。你是飞雪的粉丝，2026 年秋天站在一列开往北方的站台上，捡到一盒磁带；
每按一次播放，就回到另一个夏天的现场。集齐六盘磁带之后，你要决定：这二十年，你到底记住了什么。

**交付物：`index.html`（单文件，双击即玩，零外部资源；`src/` 是开发源，`node build.js` 生成它）。**

---

## 怎么玩

| | 桌面 | 手机竖屏 |
|---|---|---|
| 走路 | 方向键 / WASD | 左下方向键 |
| 说话 / 调查 / 确认 | Z、空格、回车 | A |
| 随身听（状态 / 磁带 / 道具） | X | B |
| 磁带盒（跳年份） | T | 右上「磁带」 |
| 选项 | 1–9 或直接点 | 直接点 |

- 点画面任意位置也能推进对话（手机上没有键盘也能读完）。
- 磁带盒里点「已获得」的年份会淡出淡入跳年；灰格是还没捡到的磁带。
- 目标：六盘磁带（2006 / 2007 / 2014 / 2020 / 2026 / ????），进 ???? 的门，看四个结局之一
  （意难平 / 各自安好 / 画地为牢 / 局外人）。结局由「执念」和「清醒」两条值决定。
- 战斗不是砍血，是「把话说清楚」：举证 / 共情 / 关掉手机，心力归零会被说服。

## 关键设计

1. **一个 320×180 的固定世界，六个时代**：同一张 40×24 的地图，按年份换调色板、天气
   （热浪 / 雪 / 雨 / 尘埃）与路灯色温。像素画全部由 canvas 现画，没有任何图片文件。
2. **磁带 = 关卡选择器 + 叙事装置**：六盘磁带既是六个年代，也是六次「你当时在哪」。
   2026 的站台是起点，???? 是终点。
3. **两条价值观**：执念 / 清醒，影响结局分支；战斗胜负、对话选项、是否追问都会改变它们。
4. **罗生门，不下结论**：2006 年的举票、2007 年的天涯帖、2020 年的视频，都只以「某个人说的」
   出现；玩家可以选「一句都不是」。结局页明确写着：公开事件有报道可循，「告密」至今没有
   第三方证据，双方各执一词，游戏不断言。所有情感解读都标注为粉丝视角的虚构。
5. **单文件构建**：`src/shell.html` + `src/game.js` + `src/ui.js` + `src/story.js`，
   `node build.js` 把三段脚本分别内联成 `<script>`（保持原作用域），产出 `index.html`；构建器会检查产物里
   没有任何 `src=` / `href=` 外部引用。`node build.js --check` 用于确认产物没过期（测试会跑它）。
6. **真重置，不用 `location.reload()`**：结局页的「再来一次」调用 `resetGame()`，清空 dialog /
   选项 / 战斗计时器 / 结局 DOM / 状态，再开一条新的渲染循环（`startLoop()` 会先取消旧循环，
   不会叠帧），然后重播开场。测试里会点这个按钮验证。
7. **屏幕外的环境光**：`#cvBg` 是主画面缩小后 cover 裁切、CSS 模糊铺满的第二层 canvas。
   宽屏的上下黑边、竖屏的大片留白因此是「场景的延续」而不是死黑；同时它不产生滚动溢出。
8. **灯光是唯一的暖源**：每盏路灯在渲染时打一圈径向光池；标题画面额外压一层暖光和曝光抬升，
   镜头会极慢地漂。

## 已知问题 / 取舍

- **竖屏画面只占屏高的 26%**（390×844 下 320×180 的画面是 390×219）。这是 16:9 世界的硬约束；
  其余空间交给环境光、手柄和对话框。没有做「竖屏裁切放大」，因为那会切掉地图两边、影响找路。
  中段仍有约 340px 的留白——它现在是一条压暗的夜色渐变，不再是「糊掉的照片」，但空就是空。
- **高树会画进上一格**：雪松的树冠从 12px 长到 26px（比人高），是靠往上画一格的
  `dot(...,负 y)` 实现的。角色站在树正后方（上一格）时，精灵仍然画在树冠**前面**——
  这台 2D 引擎没有按 y 排序角色和场景，所有物体都有这个问题，只是高树最容易看见。
- **结局页在手机上要滚**：`#ending` 是长文阅读页，`scrollHeight > clientHeight` 是刻意的滚动容器
  （measure/探针会把全屏滚动容器报成「文字溢出」，属于误报）。「再来一次」是 sticky 的，
  不滚也能点到。
- **既不是 4K 也不是高刷**：320×180 的像素画面用 `image-rendering:pixelated` 放大，
  在 1x 屏上会看到整数像素块；这是像素风的本意，非 DPR 适配。
- **没有存档**：刷新即从头开始；结局页的「再来一次」是唯一的软重开。
- **夜色偏暗**：高亮（>200 亮度）占比只有 0.1%–0.6%，因为整体是夜戏；光源靠路灯的光池和
  标题的暖光池表现，而不是大块白色。
- **磁带盒里当前年份的格子可能是灰的**（例：在 2026 但还没捡到 2026 磁带），这是诚实的：
  你人在这一年，磁带还不在你手里。
- **标题页那个小人仍然是「锐利的人 + 模糊的背景」**：那是 `#screen` 上真实渲染的角色，
  底下的 `#cvBg` 是 CSS 模糊的同一帧。要让她和环境一致，得单独给标题做一层柔焦，
  这次没做（她的脚底是有影子的，不是悬空）。
- **战斗页中间偏空**：一个 180×225 的镜框装「你的想象」，两边是纯渐变。
  想填满要么加立绘，要么加背景图层，都不是这一轮的「小修」。
- 手机上的「A/B/磁带」是屏幕按钮，不是系统手势；竖屏时它们在对话框上方、拇指区
  （y≈618–714 @390×844），横屏时贴左右中段，避免压住底部对话框。

## 画面上踩过的坑（留给下一轮）

这几条不是风格，是**在 320×180 上会被读成「渲染坏了」**的硬规则：

1. **发光不许用半透明矩形**。路灯原来是 `dot(2,1,13,6, lamp)` 的一块 22% 色块，
   4 倍放大就是「一盏发光的方盒子」；招牌辉光原来是两块叠起来的色块，直角边成了
   「招牌外面套了一个更亮的方框」。全部换成 `groundPool()` 的径向渐变 / 沿 y 的线性渐变。
2. **地面不许按格铺色**。16px 的硬边在 4 倍下就是一张方格纸。雪的明暗只交给光池、
   空气透视和软斑，没有一条直边。
3. **随机数要用 `Math.imul`**。`h*1274126177` 超过 2^53，低位被浮点精度吃掉，
   所谓「随机」雪点其实带周期——这也是地面读成网格的元凶之一。
4. **雪挂在树上是「断开的几小段」**，不是满宽的横线。满宽的横线在 4 倍下是斑马纹；
   画到树冠外面的白点，是悬空的刮痕。
5. **灯罩的溢光半径别超过灯头太多**。半径 19 的圆盘挂在 16px 的灯头上，读出来是一片雾。
