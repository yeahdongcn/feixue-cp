# 不下车 · v2（3D 单文件版）

**一句话**：一列开过二十年的车。你是车顶上的一个粉丝，躲开流言，尽力把她们留在同一个画面里。

## 怎么玩

直接双击 `dist/index.html`（或丢到任意静态服务器）。**零外部请求**：three.js 已内联，
没有图片、模型、字体、音频文件——所有几何、配色、音效都是代码现算的，一个文件就是全部。

- 桌面：`← →` 换道，`空格 / ↑` 跳，`↓` 滑铲
- 手机：左右滑换道，上滑跳，下滑铲；轻点屏幕 = 跳
- 重开：结算页的「再坐一次」走真正的 `resetRun()`，不刷新页面；带 `?shot=1` 的地址也能继续玩
- 地址栏加 `?shot=1&d=400` 可跳到指定距离截图（开发用；会随 dist 一起发布）

### 跑什么

画面里一直有**两个人**跑在你前面。她们之间有一根线，距离时近时远。

- 你跑在她们**中间那道**（和连线同框），同框值涨；被挤出去就掉。
- 同框值 0–100，直接乘分数（×1 到 ×5）。
- 70 以上，磁带会被吸过来；88 以上，替你挡一次撞击——挡完掉 42。
- 撞一次掉 14、少一颗心；三颗心用完就提前下车。
- 2007 年她们越走越远，2014 年只剩一个人（这一段怎么跑都会掉），2020 年最远，
  2026 年又近了一点，最后一年站台空了，框不住。
- 结算卡上的「同框」条和一句话，就是你这一局把她们守住了多少。

这是机制，不是旁白：你可以**守住**，也可以**弄丢**。游戏不定义她们是什么关系。

### 罗生门

2007 年段有三块碎片，在同一位置的三条道上，一局**只能带走一块**。三块分别是三种说法
（「告了密」/「没做这事」/「记错了」），每一块都写明：没有第三方证据，没有人出来对质。
结算卡会写你带走了哪一版，另外两版没拿到。游戏不替任何一版盖章。

## 关键设计

- **同框 = 唯一的可失去物**：不是血条，而是「她们还在不在同一个画面里」。它同时是
  分数倍率、磁带磁力、一次性护盾和结算文案，逼玩家在「贪分」和「守画面」之间选。
- **六站不是背景板**：每一站的剪影间距/人数写进 `PAIR_ERA`，2006 并肩、2007 越走越远、
  2014 只剩一个人、2020 最远、2026 回来一点、???? 框不住；机制和六年叙事对得上。
- **一局只带走一种说法**：三块碎片同位置不同车道，从数据层保证不可兼得；文案始终写
  「没有第三方证据」，不替任何一版定性。
- **零素材**：几何烘焙进 `BufferGeometry`，音效用 WebAudio 振荡器实时合成，颜色写死在六套
  `ERAS` 调色板里；`build.py` 把 three.js 和两个源文件内联成唯一的 `dist/index.html`。
- **真重开**：`resetRun()` 归零状态、镜头、碎片、HUD、计时器；`RUN` 局数令牌让上一局的
  `setTimeout` 失效；AudioContext 保留，不触发浏览器的「未手势播放」限制。
- **可读性按像素验**：HUD 顶部加渐变底板、年代字幕加暗底、副标题加小暗片、标题卡加深，
  然后按实际截图采样背景算对比度（见下面验收数据）；不是「看着差不多」。
- **手机优先**：`env(safe-area-inset-*)`、44px 以上点击区、短屏标题卡可滚动；
  390×844 与 375×667 都实际点过按钮、滑过车道。

## 结局

跑到尽头会切到俯视：整条轨道是一个环。文案「你跑了二十年。轨道是个圈。」/「画地为牢」。
6.2 秒后出现两个按钮：**下车** / **不下车**。两段收尾都会看你最后把同框守到了多少：
守住了、半散、散了，说法不一样——但都不会替她们把关系说死。

## 创作边界

- 玩家是粉丝，不扮演真人
- 不用真人照片、节目 LOGO、任何外部素材
- 只写公开报道与节目里出现过的事，未经第三方证实的不作断言（「告密」一说在游戏里保持罗生门）
- 标题页与结算页都有免责声明

## 已知问题

- **必须支持 WebGL**。初始化失败时只显示一条错误提示，没有 2D 降级版。
- **两侧偏黑**：1280×800 玩法帧的全屏近黑 25–46%，2014「灰」最高（46%）。这是暗角 + 车厢侧面的
  设计取向；如果要在超宽屏上更满，需要再加两侧景物，属于内容量而非修 bug。
- **桌面结算页两侧空**：卡片宽 560px，左右各约 86% 近黑，是刻意的聚焦构图；不是没画完。
- **矮屏要滚**：<700px 高的窗口/手机（如 375×667）上，标题卡与结算页都可能需要滚动；
  已能滚、按钮可点，但「再坐一次」不是第一屏可见。
- **移动端横屏**：能玩，标题卡需要滚动；3D 构图按竖屏/16:10 调过，超宽比例两侧会更空。
- **HUD 顶部底板**：为了让 11.5px 的小字在亮天空上可读，顶部压了 230px 渐变；在 2006 的亮天空
  上会牺牲一点天空亮度。这是可读性换的，不是无意压暗。
- **调试口令进包**：`?shot=1` 是开发用截图模式，随 dist 发布；不影响正常游玩，但可考虑在发布版剥离。
- **音频**：必须等用户点击后才有声音（浏览器策略），没有音量滑杆，也没有暂停键。
- **时间点计数**：`st.tlCount` 只做了统计，没有显示在结算卡上；README 旧版写的「路过 N 个时间点」
  已改成实际存在的 `●/○` 六站标记。
