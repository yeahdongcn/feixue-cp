# 不下车 · v2（3D 单文件版）

一列开过二十年的车。你是一个粉丝，在车顶上跑。

## 怎么打开

直接双击 `dist/index.html`，或者丢到任意静态服务器上。**零外部请求**：three.js 已内联，
没有任何图片、模型、字体、音频文件——所有几何、配色、音效都是代码现算的。

- 桌面：`← →` 换道，`空格/↑` 跳，`↓` 滑铲
- 手机：左右滑换道，上滑跳，下滑铲
- 地址栏加 `?shot=1&d=400` 可以跳到指定距离截图（调试用）

## 文件

| 路径 | 作用 |
|---|---|
| `index.html` | 开发版（外链 src），改代码用这个 |
| `src/world.js` | 常量、六套时代配色、世界几何烘焙、障碍/磁带数据、**时间线文本** |
| `src/game.js` | 渲染、角色、碰撞、镜头、时间线触发、结局反转 |
| `build.py` | 把三个 js 内联进 `dist/index.html`（697KB / gzip 178KB） |
| `test/world.js` | 世界构建自检：NaN、法线、三角面预算、障碍死局、时间线合法性 |
| `test/smoke.js` | 整机冒烟：DOM shim + 假渲染器，从开机跑到结局，含失败路径 |
| `test/project.js` | 相机投影扫描，验证构图（不需要 WebGL） |
| `test/render.js` | 软件光栅器，把真实几何渲成 PPM，校验明暗对比 |

```bash
node test/world.js && node test/smoke.js && python3 build.py
```

## 六个时代

`2006 → 2007 → 2014 → 2020 → 2026 → ????`，每个时代 190 米，共 1140 米，约 70 秒跑完。

每个时代道旁有一对**剪影**，两个人之间的距离就是那一年她们的距离：

| 年份 | 剪影 | 时间点 |
|---|---|---|
| 2006 | 并肩站着 | 长沙赛区，一个冠军一个季军，住同一间宿舍 |
| 2006 | 并肩站着 | 全国第五和第六，台上那句话 |
| 2007 | 背对，隔了三米多 | 三句话，两千一百层楼 |
| 2007 | 背对 | 之后近七年，行程表是空的 |
| 2014 | 只剩一个人 | 又在小场子里唱起来 |
| 2014 | 只剩一个人 | 灯牌擦干净，带去了现场 |
| 2020 | 背对，更远 | 那天台上，当场质问 |
| 2020 | 背对 | 六个字：我们不说别人了，乖 |
| 2026 | 一个先转过身 | 《后会友期》18 天，列车播放破 7 亿 |
| 2026 | 一个先转过身 | 海拔 4000 米：我是被宣判的人，我画地为牢 |
| 2026 | 一个先转过身 | 系了四次鞋带，一次都没松 |
| ???? | 空站台 | 收官，两个人都没有下车 |

跑过剪影时字幕弹出，结算卡上会写「路过 N 个时间点」。

## 结局

跑到尽头会切到俯视：整条轨道是一个环。文案「你跑了二十年。轨道是个圈。」/「画地为牢」。
九秒后出现两个按钮：**下车** / **不下车**。
