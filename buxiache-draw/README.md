# 画地为牢 · v3

> 绳长就是周长。你圈住什么，就只剩什么。

一个单 HTML 的 Canvas 2D 游戏，双击 `index.html` 就能玩，手机浏览器也能玩。
没有图片、没有字体文件、没有音频文件、没有 CDN：画面和声音都在运行时生成。

**验收状态（2026-11-13）**：`levels / play / guard` 全绿；1280×800、390×844、320×568、844×390 四档 × 五个画面全部 **0 个版式问题、0 条 console 报错**。

## 怎么玩

按住拖动，在地上画一条线。**把线绕回来接上自己**，圈就封住了。

- 圈里的东西留下，圈外的永远留在外面
- 绳子长度就是这一圈能画多长，**每一站都在变短**
- 每一站有最低要求（如“圈住 3 样”），圈不够就作废、这一笔重来
- 短按/松手没接上不会锁死，直接再画一笔即可；桌面按 `R` 可清掉当前这一笔
- 桌面按 `M` 或点右下角 `声音 · 开/关` 静音；站牌上按空格 / 回车开始

六站：`2006 → 2007 → 2014 → 2020 → 2026 → ????`

| 站 | 绳长 | 要圈住 | 那一站 |
|---|---|---|---|
| 2006 宿舍 | 1120 | 3 样 | 一个冠军，一个季军，同一间宿舍 |
| 2007 台上台下 | 1060 | 3 样 | 三句话，两千一百层楼 |
| 2014 小场子 | 990 | 3 样 | 灯牌擦干净，带去了现场 |
| 2020 麦克风前 | 820 | 2 样 | 那天台上，你问了一句 |
| 2026 四千米 | 740 | 2 样 | 海拔四千米，她说：我是被宣判的人，我画地为牢 |
| ???? 牢 | 300 | 1 样 | 绳子只剩这么长了 |

最后一站的盘上，前五站你圈住的和放手的东西全都淡淡地铺在那里——你只能再圈住一个。

## 关键设计

### 1. 手上的分量

- **笔宽跟着手速走**：慢下来墨会堆粗，快起来线会拉细；起笔收笔有锥形。
  实测一笔忽快忽慢的圈，笔宽在 `0.55×`–`1.32×` 基准宽之间，出现 10 档。
- **不做位置缓动**：`pointermove` 处理 `getCoalescedEvents()`，笔尖就在手指/鼠标的位置。
- 桌面端多一个**笔尖停靠点**（亮点 + 细环），触屏不显示，避免留下“幽灵笔尖”。
- **WebAudio 现场合成**：落笔的纸面摩擦、封口的三音和弦 + 低频、失败的低频、按钮轻点。
  声音在第一次手势时才解锁；手机有 `navigator.vibrate` 时封口/失败各给一次短震。

### 2. 封口 / 失败的反馈层次

封口这一下是分层的，不是一个大特效：

1. 收口处一颗结 + 一圈 0.9 的白闪
2. 6.5px 衰减的镜头震动（只震画布，UI 不抖）
3. 两圈扩散冲击波 + 52 颗火星 + 14 颗上浮余烬
4. 圈内亮起暖光，圈外压暗 30%，边界加一圈细光
5. 圈住的物件按 85ms 间隔逐个亮起、逐个爆小火星；放手的物件熄灭
6. 中央 `封住了 · 圈住 N 样`，1.35s 后用**墙钟**推进下一站（掉帧不会把等待拖长）

失败是另一套：红闪、4.5px 震动、20 颗余烬、红色 toast，780ms 后真正重置这一笔。

### 3. 光、层次、留白

- 背景不是纯黑：暖纸底色 + 顶灯光池 + 40 颗缓慢上浮的尘埃 + 固定种子的纸面颗粒
- 盘面有很淡的网格、同心圈、四角刻线；这些在“圈外变暗”后仍保留一点纹理
- 物件有光晕、双环和 13px 名字；前五站留下的东西在末章只留字形，不抢“你自己”
- 章节卡是场景里的一块**站牌**：板面、光、物件仍在四周；站牌出现时 HUD 和声音按钮一起让位
- 结算卡是一张可以直接截图的深色卡：标题、称号、分数、年份格、一句可复制的话、两个按钮

## 第三阶段验收修了什么

1. **结算卡在小屏 / 横屏被裁**
   - 320×568：卡高超过可视区，按钮底边被裁 7px、尾注整行出屏。
   - 844×390：结算卡被 `max-height` 截到 350px，分数、分享句、两个按钮全部出屏。
   - 修法：保留 390×844 与桌面的原版式；新增 `≤360px 宽` 和 `≤520px 高` 两套压缩规则，重排标题/分数/年份格/分享句的间距，并在矮屏隐藏非必要的尾注。现在 320×568 卡高 535px（上下各留 16px），844×390 卡高 367px（上下各留 12px），按钮都是 44px 高且完整可点。
2. **声音按钮可见但点不到**
   - 章节卡打开时 `#snd` 没有被 `body.card-open` 隐藏，但 `#card`（z-index 5）盖在 `#ui`（z-index 2）上面。结果按钮看起来还在，点下去却是“开始游戏”。
   - 修法：站牌出现时声音按钮随 HUD 一起隐藏；进入可玩状态后再出现。
   - 同时把声音按钮从 37px 高提到 **44px**（触控目标下限），手机端把它上面的提示文字抬高 10px，留出 8px 间距。
3. **复验**：上述两个问题修完后，320×568 与 844×390 的五个画面也变成 0 问题 / 0 报错；390×844 与 1280×800 的版式数字没有回退。

### 读数说明：两类误报，没有瞎改

- `shoot.js` 只检查元素自身的 `display/visibility/opacity`，不追祖先。章节卡和游戏态里，隐藏的结算卡子节点仍会被列进 `items`（所以 01–04 能看到 `eKept` 等），但它们不是可见元素。本轮只按“真的会显示”的节点处理。
- 桌面和横屏下 `#hint` 是一个全宽、`pointer-events:none` 的文本块，它的盒子与右下角 `#snd` 有 43% 的面积相交；但文字居中、按钮在右侧，实际字形没有相交，也没有挡住点击。这一条保留，没有为了探针数字去改文案位置。
- 容器与子元素（如 `#cMeta` 与其中的 `<b>`、`#eBig` 与其中的 `<b>`）天然相交，属于正常结构，不计为文字打架。

## 实现要点

- 全部 Canvas 2D，无依赖、无图片、无字体文件（用系统中文字体）
- 封口有两种判定：线条自己交叉（`segHit` + 截断到交点），或几乎绕满一圈回到起点
- 用累计转角（`G.turn`）防止“起手一个小弯就被误判成封口”
- 物件与文字画在屏幕空间，尺寸固定，所以手机上不会缩成看不清的小点
- 画的过程中有一条虚线从笔尖连回起点，靠近时起点环会亮、会呼吸；松手会闭成什么样一眼能看到
- 线条是逐点算宽后拼出的多边形带（不是恒定 `lineWidth` 的 stroke），所以粗细能连续变化
- 章节推进、失败重置、分享复制都不依赖 `location.reload()`；“再画一次”走 `loadLevel(0) + showCard(0) + 清空记录`
- 结算卡在窄屏/矮屏只压间距和字号，不隐藏分数、分享句和两个按钮；只有横屏的尾注（“截屏保存这张卡…”）因高度不足隐藏

## 已知限制

- **没有人眼/人耳复核**：所有“清楚/不空/不挤”的判断都来自 DOM 数字、像素统计和 Playwright 触控，不是看图；声音只验证到 AudioContext 正常、代码路径无报错，混音和音色仍需人耳。
- **没有真机**：触控用 Playwright 的 `hasTouch` 模拟（tap 声音/复制/重开都通过），但真实手机的触控延迟、低端机帧率、iOS Safari 的 `clipboard`/`vibrate` 行为仍未实测。
- **超宽屏和 320×480 以下未验证**：本轮补了 320×568 与 844×390；3440×1440 之类超宽屏，以及高度低于 480 的窗口没有专门版式。
- **`test/levels.js` 的版式硬阈值只覆盖 390 宽起**：320 宽时物件最近约 39px（低于脚本里的 40px 经验线），但按 13px 字号和纵向错位实测标签无重叠；没有把 320 加进硬阈值，避免用一个过粗的指标误判。
- **极尖急转的笔画可能让多边形带轻微自交**：截图夹具的圆弧路径覆盖不到这种手绘路径，需要真人乱画测试。
- **分享卡仍是“截图分享”，不是导出 PNG**：没有 `canvas.toDataURL` 下载按钮；要直接发图得先截屏。
- **`file://` 下 clipboard 因浏览器而异**：本机 Chromium 回读“已复制”；被拒时会退到 `execCommand`，再不行提示“长按上面那句话”。

## 创作边界

和 v1/v2 一致：玩家是粉丝，不扮演真人；不用真人照片、节目 LOGO 或节目素材；只写公开报道与节目里出现过的事。
“告密”一事没有第三方证据，这一版**不提、不断言**，保留为空白。
标题与结尾都不对真人下判断——这一版连一句台词都不替她们说，只给你一个圈。
游戏里的结算句是对玩家自己这一局的描述，不是对现实人物的判断。
