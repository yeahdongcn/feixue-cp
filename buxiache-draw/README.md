# 画地为牢 · v3

> 绳长就是周长。你圈住什么，就只剩什么。

一个单 HTML 的游戏，25KB，双击就能玩，手机也能玩。

## 玩法

按住拖动，在地上画一条线。**把线绕回来接上自己**，圈就封住了。

- 圈里的东西留下，圈外的永远留在外面
- 绳子长度就是这一圈能画多长，**每一站都在变短**
- 每一站有最低要求（"圈住 3 样"），圈不够就重来

六站：`2006 → 2007 → 2014 → 2020 → 2026 → ????`

| 站 | 绳长 | 要圈住 | 那一站 |
|---|---|---|---|
| 2006 宿舍 | 1120 | 3 样 | 一个冠军，一个季军，同一间宿舍 |
| 2007 台上台下 | 1060 | 3 样 | 三句话，两千一百层楼 |
| 2014 小场子 | 990 | 3 样 | 灯牌擦干净，带去了现场 |
| 2020 麦克风前 | 820 | 2 样 | 那天台上，你问了一句 |
| 2026 四千米 | 740 | 2 样 | 我是被宣判的人，我画地为牢 |
| ???? 牢 | 300 | 1 样 | 绳子只剩这么长了 |

最后一站的盘上，前五站你圈住的和放手的东西全都淡淡地铺在那里——你只能再圈住一个。

## 为什么这么设计

机制本身就是那句台词。绳子是时间，也是力气：你想留住的东西越多，圈就得画得越大，而绳子每一年都在变短。
到最后一站，绳子只够画一个很小的圈，圈里只有你自己。

和 v1（2D 像素 JRPG）、v2（3D 列车跑酷）共用同一个题材，但这版没有关卡、没有战斗、没有跑动——
**只有一个动作：画圈。**

## 文件

| 路径 | 作用 |
|---|---|
| `index.html` | 全部内容：关卡数据 + 引擎 + 样式，一个文件 |
| `test/levels.js` | 关卡可解性：凸包周长 vs 绳长，验证"能圈住 N 样、圈不住 N+1 样"，并检查四种屏幕下的版式 |
| `test/play.js` | 玩法仿真：用真实输入函数画出闭合圈，验证封口判定、失败路径、绳长耗尽、整局通关 |

```bash
node test/levels.js && node test/play.js
```

版式：iPhone 竖屏下同关两件东西最近 48px，标签宽 44px，不会重叠。

## 实现要点

- 全部 Canvas 2D，无依赖、无图片、无字体文件（用系统中文字体）
- 封口有两种判定：线条自己交叉（`segHit` + 截断到交点），或几乎绕满一圈回到起点
- 用累计转角（`G.turn`）防止"起手一个小弯就被误判成封口"
- 物件与文字画在屏幕空间，尺寸固定，所以手机上不会缩成看不清的小点
- 画的过程中有一条虚线从笔尖连回起点，告诉你"现在松手会闭成什么样"

## 创作边界

和 v1/v2 一致：玩家是粉丝不扮演真人，不用真人照片与节目素材，只写公开报道与节目里出现过的事，
未经第三方证实的不作断言。标题与结尾都不对真人下判断——这一版甚至连一句台词都不给她们，只给你一个圈。
