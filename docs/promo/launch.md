## 二、豆瓣小组

**配图**：`02-结局-你的版本她的版本.png` + `04-考据-十二条料七条经得起查.png`
**备注**：约 1000 字。豆瓣小组不吃"安利"，吃"你为什么非做不可"。所以这篇不推销游戏，交代取舍，包括我做错的部分。
**为什么这么写**：这里的人会点进仓库看。与其藏拙，不如把勘误主动摆出来——这是这个项目唯一诚实的姿态。

```text
四个游戏，和一件我始终没查清的事

2006 年夏天，长沙赛区。主持人问厉娜投票标准。她说「于公于私，于情于理」，然后举起了许飞的手。

这个镜头我看了很多遍。直到今年重看，我才意识到自己一直在做一件事：把画面，和我对画面的解释，混在一起。

今年十月，她们在一档节目里重新坐上同一趟车。收官有「下车」环节，两个人都没有下车，是整季唯一一对。

我想做点什么。但我很快发现，我想做的不是「还原」——我做不到，也不该做。

不写私生活。不用真人照片、节目 LOGO、节目影像和音频。不替她们编内心戏。

所以四个游戏里，玩家几乎都不是她们，是那个坐在屏幕前的人。

一开始我只想做一款。写到第三幕就卡住了：一段二十年的往事，不是一个动词能装下的。

捡：所有碎片散在车厢里，你能带走的有限。
跑：七十秒冲过二十年，跑到终点，轨道折回来，是一个环。
圈：绳子就是周长。圈住什么，就只剩什么。
改：你可以回到任何一年，但改得动的只有你自己。

四个玩法毫不相干，底色是同一份。

最难处理的是「告密」。

厉娜指控许飞泄露了她解约、接私活的计划；许飞否认，被追问时松口说「可能说过，不止我一个人接私活」。没有录音，没有第三方证据，到今天也没有任何一方被证实。

我可以选一边，写得更像戏。但那是在替真人下判断。

所以游戏里这一格永远是空的。你可以选信谁、不信谁，四个选项都不解锁真相——因为现实里也没有第五个选项。

顺带说一件我自己的错。最早的版本里，我把两个主语写反了：把「我画地为牢」写成了厉娜说的，把告密写成了许飞指认。四个游戏一起错。

发现的时候我犹豫了很久要不要悄悄改掉。

最后改了，并且把勘误留在仓库里。这个项目最不该做的，就是把错的说得理直气壮。

还有一件小事：鞋带。

2026 年有个镜头，选车的时候，有人蹲下去系鞋带。网友逐帧读出来「鞋带根本没松，她在等她」。画面是真的，动机是读出来的。

游戏里我把这两件事分开计分。按住不放，你会看到「鞋带一次都没有松过」——那是画面。而「她在等她」，是你自己补上去的。

这些设计不好玩。我知道。但四款游戏共享的那个结论，我不想用台词灌给玩家：

感受可以是真的。事实得另算。

地址：https://yeahdongcn.github.io/feixue-cp/
不用下载，不用注册，手机能玩。四款都能单独成立，从哪一款进去都行。

非官方同人。人物是真实的公众人物，情节基于公开报道与节目画面改编，不构成对任何人的事实主张。
```

## 四、B 站专栏

**配图**：四张卡按顺序插在文中（入口 → 结局 → 金句 → 考据）
**备注**：约 1600 字，带小标题。B 站专栏读者要的是「怎么想出来的」，不是「有多好玩」，所以这篇全讲取舍，不讲卖点。
**为什么这么写**：把设计决策摊开，本身就是内容。愿意读到末尾的人，会自己去点链接。

```text
同一段往事，为什么值得做成四种玩法

先说结论：这四个游戏不是四章，是四种「靠近」的姿态。

一、如果做成四章

最开始我只想做一款剧情向的游戏，六个章节，从 2006 年一路走到 2026 年。

写到第三幕我卡住了。

卡住的原因不是没素材，是素材太多了。这段往事里，能查证的、只是网友读出来的、到今天仍然没有答案的，混在一起，而且长得一模一样。

如果做成线性章节，玩家会以为自己在推进剧情。但这段往事没有剧情可以推进——它已经发生完了，而且有一部分永远不会被确认。

所以我把它拆了。不是拆成章节，是拆成四个动词。

二、四个动词，四种无力感

捡。《不下车》的像素 RPG。六个时代，六盘磁带，三场战斗，六个结局。你能捡的东西比车厢里有的少得多。捡得越多，越像你自己，也越不像你以为的那个人。

跑。3D 跑酷。七十秒跑过二十年。你以为在往前，跑到终点，轨道折回来，是一个环。

圈。《画地为牢》。绳子就是周长，圈住什么，就只剩什么。六站，绳子一年比一年短，最后一站你只圈得住自己。

改。《各执一词》。你可以扮演许飞，也可以扮演厉娜，回到任何一年，重新决定当时的自己怎么做。

四个动词，其实对应四种同一种感觉：你能做的事，比你想做的少。

三、让机制替事实说话

有几个设计，是为了「不撒谎」，不是为了好玩。

第一个是「料」。游戏里散落着 12 条材料，经得起查的只有 7 条。捡起来的时候，系统会标注：公开可查 / 罗生门 / 无法证实。你捡得越多，你的档案越厚，但它永远不会变成真相。

第二个是鞋带。2026 年有个镜头，选车的时候有人蹲下去系鞋带。网友逐帧读出来「鞋带根本没松，她在等她」。画面是真的，动机是读出来的。游戏里这两件事分开计分：按住不放，画面计数；「她在等谁」，你自己补。

第三个是《各执一词》的结局。两栏并排：你的版本，她的版本。她的那一栏由档案固定生成，和你做了什么无关。

你重来一百次，她还是她。

这不是难度设计，是这段关系的结构。

四、最难做的一格，是空白

「告密」这件事，是整段往事里最重的一块。

厉娜指控许飞泄露了她解约、接私活的计划；许飞否认「没有动机也没有能力」，被追问时松口「可能说过，不止我一个人接私活」。没有录音，没有第三方证据。

玩家可以选「我信许飞」「我信厉娜」「我不信任何人」「我不知道」。

四个选项，没有一个解锁真相。

有人建议我加一个隐藏结局，集齐条件就能看到「真正发生了什么」。我没加。

因为现实里没有那个隐藏结局。加了，这个游戏就变成了替真人断案。

五、一个我改过的错

最早的版本里，我把两个主语写反了：把「我画地为牢」写成了厉娜说的，把告密写成了许飞指认。四款游戏一起错。

改的时候我犹豫过要不要悄悄改掉。最后还是留了一条勘误。

做这种题材，改错的记录比「正确」本身更有说服力。因为正确是结果，改错是过程，而这个过程恰好就是我想让玩家体验的东西：你以为是那样，后来发现不是，然后你得决定怎么办。

六、技术上只有一个原则：零素材

四款游戏都是单个 HTML 文件，零外部依赖，零网络请求。

噪点是 ImageData 随机像素，天空是着色器，音效是 WebAudio 现场合成。四款游戏里没有一个二进制素材文件，没有一张真人照片，没有节目 LOGO，没有节目影像，也没有任何一首真实歌曲的旋律——配乐全部原创。

不只是版权问题。用她们的照片，这个作品就变成了「关于两个真人」；不用，它才是「关于看她们的我们」。

七、它不是还原

四个游戏共享一个结论，但谁也不是靠说教得出的：

感受可以是真的。事实得另算。

地址：https://yeahdongcn.github.io/feixue-cp/
不用下载，手机上就能玩。四款都能单独成立。

非官方同人，不构成对任何人的事实主张。
```

## 发布顺序建议

1. **豆瓣** 先发（长文需要沉淀，也最容易被截图搬运）。
2. 隔一天发 **B 站专栏**，把方法论坐实。
3. 再隔一天发 **小红书**，用金句卡做首图。
4. **微博** 最后发，单图 + 短文案，用来收口。

同一张卡不要四平台同一天用同一句文案——那是投放，不是作品。
