# 分享卡 · 两套

同一批四张卡，出两版。原因很简单：**小红书对图内二维码和外链限流**，
带码的那套发上去会被压。所以按平台分开发。

| | 用在哪 | 有什么 |
|---|---|---|
| `with-qr/` | 微博、豆瓣、B站、朋友圈、公众号 | 二维码 + 一行短链，读者能直接扫进来 |
| `no-qr/` | **小红书**（以及任何对二维码敏感的平台） | 无二维码、无外链、无「扫码」字样，只留作品名 |

## 四张卡分别是什么

| 文件 | 内容 | 适合放哪 |
|---|---|---|
| `01-entry.png` | 四个游戏一图说清 | 首图 / 封面 |
| `02-ending.png` | 各执一词：你的版本 / 她的版本 并排 | 讲到玩法的位置 |
| `03-quote.png` | 金句卡「我画地为牢，厉娜。」 | 首图（小红书优先用这张） |
| `04-ledger.png` | 十二条料七条经得起查 | 考据向的帖子 |

尺寸：`01` `02` 是 1080×1440（3:4，小红书原生比例），`03` `04` 是 1080×1350（4:5）。

## 重新生成

```bash
cd _src
node render.js        # → ../share-cards/with-qr/
node render-noqr.js    # → ../share-cards/no-qr/
```

`render-noqr.js` 会把 `.qr`、`.url`、`.url-sm` 全部摘掉，并把 footer 收成单列，
最后自检「画面里还有没有二维码 / 外链 / 扫码字样 / 横向溢出」，有一项不合格就报 ✗。

## 发布时注意

- 小红书**正文里也别写网址**。想让人找到，把地址放在**个人简介**或**第一条评论**。
- 微博那条链接是明文，可以放正文，但别和二维码图一起发（重复触发风控）。
- 豆瓣相册对二维码不敏感，用 `with-qr/`。
- 四张图别九宫格一次发完，一次一到两张，留出被追问的空间。
