# 传播风险清单

> 这个作品的地基是「有些事说不清」。传播时最容易犯的错，就是把说不清的说成说清了。
> 以下不是建议，是底线。发布前请逐条对照。

---

## 一、绝对不能说

| 不能说 | 问题在哪 | 改成 |
|---|---|---|
| 揭秘 / 真相 / 实锤 / 独家 / 坐实 / 证实了 | 「告密」没有录音、没有第三方证据，任何一方都未被证实 | 「没有录音，没有第三方证据」「到今天仍然没有答案」 |
| 许飞告密 / 许飞出卖了厉娜 | 把单方指控写成事实，直接构成名誉权风险 | 「厉娜指控许飞泄露了她的计划；许飞否认」 |
| 厉娜被雪藏是因为许飞 | 雪藏是事实，因果从未被证实 | 「2007 年末到 2014 年，她的行程近乎空白。原因各方说法不同」 |
| 她等了她二十年 / 她一直爱着她 | 动机推断，当事人从未确认 | 「网友逐帧读出来的是……；没有人确认过」 |
| 两人是 / 不是那种关系 | 私生活与性向推断，越界 | 不写、不答、不暗示 |
| 还原真实 / 真实事件改编 / 纪录片 | 暗示纪实性，抬高了事实主张 | 「基于公开报道与节目画面改编」「一次重构」 |
| 官方 / 正版 / 授权 / 联名 | 非官方同人，冒用身份 | 「非官方同人」 |
| 她终于承认了 / 松口承认告密 | 原话是「可能说过，不止我一个人接私活」，不等于承认告密 | 直接引原话，不加解读 |
| 把「雪藏七年」当梗、当笑点、当糖 | 消费他人真实的低谷 | 不写；要提就平实地提 |
| 「磕到了」「好甜」用来形容指控那一段 | 把伤害浪漫化 | 感情和事实分开说 |
| 拿天涯截图、聊天记录、所谓「内部消息」当证据 | 原帖已删、来源不明 | 标明「无法证实」，并且不作为素材二次传播 |
| 我替她们说句话 / 她们应该感谢我 | 代言真人 | 「我不替任何人说话」 |

**一条总则**：凡是句子里出现「其实」「原来」「真相是」，停下，重写。

## 二、每句话都要带的限定词

这五条是传播中最容易写反的。发之前逐字对一遍。

1. **2006 年 PK 台**：「于公于私，于情于理」是**厉娜**说的，说完举起了**许飞**的手。
2. **画地为牢**：「我是被宣判的人，我能去哪儿啊。我画地为牢，厉娜。」是**许飞**对**厉娜**说的。回屋后用 AI 查这四个字、然后点了麦当劳的是**厉娜**。
3. **告密**：**厉娜**指控**许飞**；**许飞**否认「没有动机也没有能力」，被追问时松口「可能说过，不止我一个人接私活」。**没有录音，没有第三方证据。**
4. **雪藏**：2007 年末到 2014 年，**厉娜**的行程单近乎空白。
5. **鞋带**：画面是真的；「鞋带没松，她在等她」是网友逐帧读出来的，没有当事人确认。

> 这五条在最早的版本里，第 2、3 条的主语写反过。四个游戏一起错，后来一起改了。
> 传播时如果看到有人引用旧版说法，不用争，把 [`buxiache/考据.md`](../../buxiache/考据.md) 发过去就行。

## 三、遇到「你在消费真人」怎么回

### 先记住五条原则

1. **不辩论动机。**「你是不是想红」无法证伪，越辩越像。
2. **只讲做法，不讲情怀。** 可核查的事实比「我是真心喜欢她们」有说服力。
3. **承认边界。** 她们是真人，这个作品没有资格替她们说话。
4. **允许对方不认同。** 不需要说服，只需要说清楚。
5. **给一个动作。**「哪一处越界，指出来，我改或下架。」

### 三段可以直接用的回复

**通用版**

> 你说得对，她们是真人，这件事不该由我替她们决定。
> 所以这个作品里没有她们的照片、影像和歌，也没有替她们编私生活。能查的我标了出处，查不到的就说查不到。
> 如果你觉得哪一处越界了，指出来。我改，或者下架。

**「你凭什么替她们编故事」**

> 我没有替她们说话。四个游戏里，玩家扮演的几乎都是粉丝；唯一能扮演本人的那一款，另一方的反应锁在档案里，你改不动。
> 我想写的是「看的人」，不是「被看的人」。

**「吃人血馒头 / 蹭热度」**

> 不接广告，不带货，没有付费，也没有打赏。
> 做完放在那儿，谁都能玩，不玩也不损失什么。
> 如果你认为这件事本身就不该做，我尊重这个判断——但我不会用「我是粉丝」来给自己开脱。

### 千万不要说

- 「我是粉丝，我有资格。」
- 「你不也看了？」
- 「这是艺术自由。」
- 「她们又不会看到。」
- 「你这么较真干嘛。」
- 反过来质问对方的立场。

### 不要做的事

- 不要 @ 任何一位当事人，也不要在评论区点名她们来「回应」。
- 不要删除合理的批评。只删人身攻击、隐私爆料和谩骂。
- 不要组织人去「冲」任何一个账号，包括批评者。

## 四、版权边界

### 为什么不用真实歌曲

一首歌身上叠着好几层权利：词曲的**著作权**、录音的**录音制作者权**、演唱的**表演者权**。

把一首歌 MIDI 化、改个调、换个编曲，都落进**改编权**；传到网上，落进**信息网络传播权**。哪怕「只用了旋律」「只用了十秒」「没用来赚钱」，也一样。

所以四款游戏的配乐**全部原创**，音效是 WebAudio 现场合成的。四款游戏里没有一个音频文件。

这不只是规避风险。用了她们的歌，玩家记住的就是那首歌；不用，记住的才是这个作品。

### 为什么不用节目影像和 LOGO

- 节目画面是**视听作品**，截图、二创、做成表情包传播，都需要授权。
- 节目 LOGO 是**商标**，用在同人作品上会造成来源混淆。
- 真人的脸涉及**肖像权**，节目里的每一帧都属于此列。

所以所有视觉都是抽象符号：白 T 恤、吉他弦、雪花、列车窗、一根鞋带、一根绳。四款游戏的画面全部由代码实时生成，没有一个图片素材。

### 台词怎么用

- **少量、必要、注明出处。**「于公于私，于情于理」这种短句，独创性有限，但仍然标注来源，不据为己有。
- **不做成商品。** 不印 T 恤、不做周边、不放进付费内容。
- **不做标题党。** 不用台词做「震惊体」标题，不用它引流到无关内容。
- **不脱离语境。** 金句卡必须带着说话人和场景一起发，不能只截半句。

### 同人的边界

- **非商业。** 没有广告、没有付费、没有打赏、没有联盟链接。
- **非官方。** 标题、域名、视觉都不模仿官方；不使用「超级女声」「芒果TV」等名称做标识。
- **不混淆来源。** 每一处露出都带「非官方同人」。
- **可下架。** 当事人或权利方提出异议，立刻下线，不谈判。

## 五、平台与运营风险

| 风险 | 处理 |
|---|---|
| 话题被限流 / 引战 | 不买热搜、不刷量、不组织转发。数据不好看就不好看。 |
| 评论区出现对真人的攻击 | 删人身攻击与隐私爆料；保留合理批评；置顶一条事实说明。 |
| 有人爆料「内幕」 | 不转、不存、不回。截图也不接。 |
| 内容被搬运、被二创 | 不争吵。补一句出处和声明即可。 |
| 被指「拿真人赚钱」 | 出示：无广告、无付费、无打赏、仓库公开。 |
| 当事人或经纪方提出异议 | **立即停发、下线、公开说明、保留沟通记录。** 这是底线，不是谈判。 |
| 未成年人看到 | 没有付费点，没有抽卡，没有引导消费。 |

### 发布节奏上的两个提醒

1. **不要四平台同一天发同一套话。** 那会被读成投放。按 [`launch.md`](launch.md) 的顺序隔天发。
2. **金句卡不要单发。** 「我是被宣判的人」脱离上下文，会被读成对另一方的指控。金句卡必须和入口卡或结局卡一起发。

## 七、如果还是出事了

三步，按顺序：

1. **停。** 暂停发布，不再新增内容。
2. **删。** 下线争议内容，不删沟通记录。
3. **说。** 用一段不辩解的话说明：哪里错了、改了什么、后续怎么办。

模板：

> 这段内容有问题，我已经下线。
> 具体是：（一句话说清错在哪）。
> 会改成：（一句话说清怎么改）。
> 给当事人和读者添了麻烦，抱歉。

不要写「如果让你不舒服」，不要写「但是我的本意是」。本意不能抵消结果。
