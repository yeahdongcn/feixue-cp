# 《不下车》· 考据与梗词典

做这个游戏时，我把能查的都查了一遍。下面这张表是它的地基——
**哪些是公开可查的，哪些只是网友读出来的，哪些到今天仍然没有答案。**

---

## 一、时间线

| 时间 | 发生了什么 |
|---|---|
| 2006.06 | 《超级女声》长沙赛区：**厉娜冠军，许飞季军**。两人同住一间宿舍。 |
| 2006 夏 | PK 环节被问投票标准，厉娜说「**于公于私，于情于理**」，然后举起许飞的手。这是这段关系最著名的镜头。 |
| 2006.09 | 全国总决赛：**厉娜第 5，许飞第 6**。名次差一位。 |
| 2007 前后 | 厉娜把解约、跳槽、接私活的打算告诉了许飞。几天后，公司高层就知道了。 |
| 2007 末–2014 | **厉娜**行程单近乎全空，连收三封律师函，通告叫停。**近七年。** |
| 2020.04 | 一档怀旧综艺让 06 超女重聚。许飞当场质问尚雯婕「私信为什么从不回」，唐笑补刀「我们有聚，只是我们总是没有你」。当夜许飞发长文。 |
| 2026.10 | 芒果TV《后会友期》：18 天列车旅行，四对走散的旧友。有效播放破 7 亿，云合综艺市占率一度近六成，服务器崩了两次。 |
| 2026.10 | 名场面：**选车时系鞋带** / 海拔约 4000 米悬崖小屋，**许飞**对厉娜说「**我是被宣判的人，我能去哪儿啊。我画地为牢，厉娜。**」/ 厉娜回屋**用 AI 查「画地为牢」**然后**点了麦当劳**。 |
| 2026.11 | 收官「下车」环节：**双方都没有下车**，整季唯一一对。互道「感谢我的人生你曾出现过」。 |
| 2026.11 | 编剧于正深夜发视频「我们给厉娜发的视频，**磕生磕死的追**」。 |

> 这一栏是游戏里那个「料」系统的原型。**12 条料，经得起查的只有 7 条。**
> 这不是要否定谁的感受，是想说：感受可以是真的，事实得另算。

## 三、梗词典

- **飞雪** —— 两人的 CP 名，贴吧时代叫起来的。
- **于公于私，于情于理** —— 厉娜 2006 年的投票宣言，粉丝的圣经。
- **我画地为牢** / **我画地为牢，厉娜** —— 节目原话（许飞说的，对着厉娜）；后来变成「我＋成语，某某」的万能句式。
- **我刻舟求剑，厉娜没开船** —— 同一个句式的另一半。一个人记着船的位置，另一个人根本没打算开船。
- **系鞋带** / **鞋带根本没松** —— 2026 年最出圈的二创素材。
- **一个内耗，一个松弛** / **转头点麦当劳** —— 深情与钝感的错位。
- **不下车** —— 收官环节；也是这个游戏的名字。
- **这糖兑水能喝十年** —— 节目里的另一对（马天宇 & 张萌）的梗，被顺手挪用过来。

## 四、做游戏时的几个取舍

1. **不让你扮演许飞或厉娜，让你扮演那个粉丝。**
   替真人编内心戏是不体面的。但「粉丝怎么想」是可以写的，而且这才是这个故事里最真实的一层。

2. **「告密」永远不给答案。**
   游戏里你可以选「我信许飞」「我信厉娜」「我不信任何人」「我不知道」——四个选项都不解锁真相。因为现实里也没有第五个选项。

3. **把「画面」和「解读」拆开标注。**
   鞋带那一段，玩家按住不放会看到「鞋带一次都没有松过」——那是画面。而「她在等他」是你自己补上去的。游戏让这两件事分开计分。

4. **不用真人照片、不用节目 LOGO、不写任何私生活。**
   所有视觉都是抽象符号：白 T 恤、吉他弦、雪花、列车窗、一根鞋带。
